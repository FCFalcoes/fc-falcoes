# FC Falcões — site inicial

Este é um site estático (HTML, CSS e JavaScript), preparado para publicação gratuita na Vercel.

## Pré-visualizar no computador
Abra o ficheiro `index.html` num navegador.

## Publicar na Vercel
1. Crie uma conta gratuita em https://vercel.com/
2. Crie um repositório no GitHub e carregue todos os ficheiros desta pasta.
3. Na Vercel, escolha **Add New → Project** e importe o repositório.
4. Como é um site estático, não precisa de comando de build. Se a Vercel pedir uma pasta de saída, deixe a raiz (`./`).
5. Clique em **Deploy**.

Também pode importar o projeto diretamente na Vercel a partir do GitHub.

## Dados confirmados
- Escola de Formação FC Falcões.
- Localização: Nampula, Moçambique.
- Faixa etária: 6 aos 17 anos.
- Não existe formulário de inscrição online; o site apresenta informação de contacto.

## Personalização pendente
- Inserir número de telefone/WhatsApp e/ou e-mail oficial do clube.
- Adicionar nomes, números e posições dos jogadores, se desejado.
- Inserir calendário, resultados e notícias reais.

Os contactos não foram inventados: a secção de contactos informa que os dados oficiais serão acrescentados quando forem fornecidos.
